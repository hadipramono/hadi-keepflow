# Hadi KeepFlow v1.3.4 — Phase 3.5: Dashboard & Personalization

## Dashboard
- Added a dedicated Dashboard entry and landing view.
- Added statistics for active notes, pinned notes, notes updated today, and archived notes.
- Added a five-note recent activity list with direct open action.
- Added category distribution bars and shortcuts to category views.
- Added greeting based on local time and optional display name.

## Personalization
- Added display name preference.
- Added system, light, and dark theme preference; system theme follows OS changes.
- Added default grid/list layout preference.
- Added default sort preference.
- Preferences stored in `hadi_keepflow_preferences_v1` in browser LocalStorage.

## Compatibility
- No backend `.gs` changes.
- No Google Drive folder, Markdown, metadata, or note schema changes.
- Existing LocalStorage keys and sync queue remain unchanged.
- Backup manifest application version updated to 1.3.4.
